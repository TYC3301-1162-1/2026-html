# 风栖小记静态博客

直接打开 `index.html` 即可浏览。全部内容与图片为本地文件，无数据库、构建步骤或线上接口依赖。

公共样式位于 `css/style.css`，交互位于 `js/main.js`，配图与站标位于 `images/`。新增或修改文章时，同时修改相应详情页、列表卡片和相关推荐；网站未接入内容管理后台。

留言为本地演示：只有同意保存后才写入当前浏览器，最多 20 条，不保存邮箱，也不发送到服务器。不同浏览器之间不会同步。

GitHub Pages 可直接托管此目录。所有链接使用相对路径，支持仓库子路径部署；发布后请再次核对文章和图片访问。

图片取得地址见 `sources.html`。图床存储位置不等同于插画原创署名或再分发授权。
